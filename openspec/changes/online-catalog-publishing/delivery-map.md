# Online catalog delivery map

## Review decision required

This is a corrected roadmap, not implementation approval. Every delivery is an independently demonstrable behavior with its tests in the same slice; no infrastructure-only fallback is permitted. Estimates are provisional forecasts of authored additions plus deletions, including tests/docs, and are capped at 400. Stop and ask on risk before crossing that cap.

**Shared rules:** Preserve the catalog component topology and visual language while suppressing mock-only behavior until its delivery. Use MXN; initially omit `priceListId`, retain the resolved response ID, and expose no selector. Never expose/send price sorting. Treat nullable/HIDDEN stock neutrally; `CUSTOM_QUANTITY` status may be null and quantity `0` is not out-of-stock. Cart validation is not checkout: no orders, WhatsApp, or telephone flow.

**P0 preparatory unit — candidate; local P0 checks passed.** The prior D1.A–D responsive-only/oversize subdivision and temporary inline-shell candidate remain rejected. P0 adapts the five catalog SFCs: Header/Footer/theme and visible-disabled branch/search/category/sort/cart controls remain, while mock product/card/modal/drawer/contact behavior is unmounted. It is not anonymous D1 and changes neither router/main/auth nor D2–D14. Prior unit/build plus responsive type and focused browser evidence pass (2/2, local 375×667/1280×800 attachments); this is not a final verification, delivery, or commit claim. Exact authored count including `apply-progress.md`: **154 additions + 235 deletions = 389 changed lines**.

## First delivery boundary — D1 only

**Concrete existing touchpoints:** `src/features/catalog/api/catalog.api.ts:1-18` is the mock adapter/import boundary; `src/features/catalog/composables/useCatalogStore.ts:1-80` holds branch state and the `centro` fallback; `src/features/catalog/views/CatalogView.vue:1-22` mounts initialization; `src/features/catalog/components/CatalogHeader.vue:1-49` owns branch selection; `CatalogProductGrid.vue:1-37` currently turns absent products into a misleading result state; and `src/app/router/index.ts:358-361` owns the public slug route. There are no existing catalog tests; D1 adds focused tests under the catalog feature using the shared Vitest setup (`vitest.config.ts:7-13`) plus mocked responsive evidence (`playwright.responsive.config.ts:24-43`).

**In:** anonymous branch discovery; valid/invalid slug handling; selected-branch route synchronization; selected branch name/address landing; loading/empty/429/5xx/retry states; D1 tests and responsive evidence.

**Out:** every product endpoint/request and list/card/pager; search/categories/detail/variants/cart/validation; all authenticated controls; price selector/sort; local stock/price computation; backend edits/deployment claims; visual redesign; phone/WhatsApp/orders.

**Unavailable controls:** P0 retains the header/category/grid/footer shell and visual language while disabling branch/search/category/sort/cart affordances and showing no fake listing. It unmounts current mock detail/cart/WhatsApp actions and removes mock-derived identity, categories, price, and count claims until a later slice supplies real behavior.

## Sizing evidence and remaining risks

- The old D1 conflated `catalog.api.ts:1-111`, `catalog.types.ts:1-157`, `useCatalogStore.ts:1-168`, and visible UI hotspots `CatalogHeader.vue:1-109`, `CatalogProductGrid.vue:1-37`, `CatalogProductCard.vue:1-123`, plus new tests. This evidence supports D1/D2 separation; it does not guarantee either estimate.
- The branch landing must use documented HTTP fixtures, not real deployment data; the backend guide explicitly disclaims deployment confirmation (`public-online-catalog-frontend-guide.md:1015-1019`).
- `read:TenantCatalogSettings` and `update:TenantCatalogSettings` are confirmed. The authenticated navigation owner/placement remains a design choice, not a permission unknown.
- The guide still advertises price sort strings, but authoritative clarification prohibits frontend price sorting; request a guide correction separately.
