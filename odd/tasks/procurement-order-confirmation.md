  A. Every PurchaseOrder response (GET /:orderId, POST create, PUT /:orderId/draft, POST confirm, POST cancel) adds: status 'DRAFT'|'CONFIRMED'|'CANCELLED'; supplierCurrentVersion number|null; referenceToken string|null (opaque, never computed by the FE); canConfirm boolean (DRAFT, no issues, token and supplier version non-null; false when closed); confirmedAt/cancelledAt ISO|null; confirmedBy/cancelledBy {displayName}|null. Snapshots are frozen after CONFIRMED. validation.issues is [] when closed.
  B. POST /procurement/purchase-orders/:orderId/confirm with Idempotency-Key and a closed body {expectedVersion, expectedSupplierVersion: number|null, expectedReferenceToken: string|null} → 200 CONFIRMED, version+1. Check order: ORDER_VERSION_CONFLICT → ORDER_STATE_CONFLICT → ORDER_NOT_READY (no supplier) → SUPPLIER_VERSION_CONFLICT → SUPPLIER_ARCHIVED → ORDER_NOT_READY (token null) → ELIGIBILITY_CHANGED → ORDER_NOT_READY (other issues).
  C. POST /:orderId/cancel with Idempotency-Key and body {expectedVersion}. DRAFT|CONFIRMED → CANCELLED (terminal), no reason. Errors ORDER_VERSION_CONFLICT, ORDER_STATE_CONFLICT.
  D. PUT /draft and DELETE on a non-DRAFT order → 409 ORDER_STATE_CONFLICT (the version check runs first).
  E. List: optional status=DRAFT|CONFIRMED|CANCELLED (single value, otherwise 400 MALFORMED). The cursor is bound to status. The summary status is widened. No counts.
  F. Error envelope {statusCode, error: Code}, value-free. New 409 codes: ORDER_NOT_READY, ELIGIBILITY_CHANGED, SUPPLIER_VERSION_CONFLICT, ORDER_STATE_CONFLICT. Existing: ORDER_VERSION_CONFLICT, SUPPLIER_ARCHIVED, IDEMPOTENCY_KEY_CONFLICT, IDEMPOTENCY_KEY_IN_FLIGHT, plus 400/401/403/404/500.
  G. Idempotency as in O3b: scoped per tenant+actor+operation+order, only successes are stored, a fresh key per deliberate attempt after a re-read.
  H. Confirm needs create:ProcurementOrderConfirmation + read:ProcurementPurchaseOrder. Cancel needs create:ProcurementOrderCancellation + read:ProcurementPurchaseOrder. No fixed roles. Edit permissions are not required.
  I. Zero stock, reservations, payments, debt or events. Readable seeds only.
